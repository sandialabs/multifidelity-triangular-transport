# Software authorship and citation

MFTT is developed by Owen Davis and Gianluca Geraci and distributed under the
[MIT License](../LICENSE).

MFTT implements the methods in:

> Owen Davis, Daniel Sharp, Youssef Marzouk, and Gianluca Geraci,
> [*Multifidelity Formulations for Triangular Transport*](https://arxiv.org/abs/2610.00698), arXiv:2610.00698,
> 2026.

The repository documentation aims to align with the naming conventions in the manuscript.
