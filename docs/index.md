# MFTT documentation

MFTT (Multifidelity Triangular Transport) provides sample-trained monotone
triangular maps for target distributions with scarce high-fidelity data.

The documentation follows the notation and method names of the submitted
manuscript *Multifidelity Formulations for Triangular Transport*. Start with the
notation guide, choose a map family, and use its rendered notebook for a full
paper-to-code walkthrough.
